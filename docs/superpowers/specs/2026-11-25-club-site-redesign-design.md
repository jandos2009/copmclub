# Редизайн сайта клубной платформы — «Городской сервис»

## Задача

Сделать публичную часть сайта и личный кабинет спокойными, просторными и понятными для любой аудитории: без визуального шума, с крупной типографикой, ясными действиями и бережной к глазам палитрой. Сохранить возможность выбрать светлую/тёмную тему, акцент и фон с фотографией компьютеров.

Утверждено пользователем:
- направление «Городской сервис»;
- настройки «Тема + акцент + фон»;
- бесплатное стоковое фото с компьютерами;
- можно переделывать не только список клубов, но и остальные страницы.

## Цели

1. Единая визуальная система для `clubs.html`, `profile.html`, `login.html`, `index.html` (регистрация), `apply.html`, `terms.html`, `privacy.html`.
2. Светлая тема по умолчанию с учётом системной; тёмная — переключателем.
3. Три акцента и два варианта фона, выбор сохраняется в `localStorage`.
4. Понятный список клубов: заголовок → адрес → режим работы → преимущества → действия.
5. Личный кабинет: приветствие, активные брони, заявки на подключение клуба, быстрые ссылки, настройки, выход.
6. Аккуратная адаптивность от 360 px, без горизонтальной прокрутки.

## Вне рамок

- Новые роли, права доступа и платежи.
- Переписывание данных или миграции БД.
- Полный редизайн `menu.html` и админки — отдельный этап.
- Замена lux-структуры `club.html`; на первом этапе только совместимость с темой.

## Визуальные решения

### Палитра

Светлая тема:
- фон `#f7f5f0`, поверхность `#ffffff`, мягкая поверхность `#efede6`;
- текст `#1f2a24`, вторичный `#5f6b64`, граница `#dedbd2`;
- основной акцент — глубокий зелёный `#0f766e` (белый текст на кнопках).

Тёмная тема:
- фон `#101512`, поверхность `#19201c`, мягкая поверхность `#202822`;
- текст `#eef2ee`, вторичный `#9aa79e`, граница `#2a352e`;
- акцент `#5eead4` (тёмный текст на кнопках).

Дополнительные акценты:
- янтарный: светлый `#b45309`, тёмный `#fbbf24`;
- синий: светлый `#1d4ed8`, тёмный `#60a5fa`.

Контраст текста и кнопок — не ниже WCAG AA. Акцент используется точечно: главная кнопка, активный фильтр, ссылки, фокус.

### Типографика

- Заголовки: `Georgia, "Times New Roman", serif` — спокойный «городской» характер.
- Интерфейс и текст: `"Segoe UI", system-ui, -apple-system, sans-serif`.
- Размеры: h1 `clamp(34px, 5vw, 56px)`, h2 `clamp(24px, 3vw, 34px)`, основной текст 16–18 px, вторичный 14–15 px.
- Межстрочный интервал 1.55–1.7, максимум строки 65–72 символа.

### Сетка и пространство

- Контейнер 1180 px, боковые отступы 20 px; на мобильном 16 px.
- Шаг 8 px: 8, 16, 24, 32, 48, 64.
- Радиусы: 12 px для полей, 18 px для карточек, 24 px для крупных блоков.
- Тени почти отсутствуют; глубина — за счёт границ и мягких поверхностей.

### Фотография

- Локальный файл `public/assets/club-bg.jpg`.
- Источник: Unsplash, автор Ella Don, «a room with a desk, computer, and two monitors», Unsplash License.
- Фото используется только в hero-блоке, не под текстом карточек.
- Поверх фото — тёмный градиент и лёгкое обесцвечивание, чтобы не спорить с текстом.
- Режим «Без фото» заменяет снимок на спокойный градиент.

## Настройки

Хранятся в `localStorage`:
- `club-theme`: `system | light | dark`;
- `club-accent`: `green | amber | blue`;
- `club-bg`: `photo | plain`.

Тема применяется до отрисовки через `theme.js` в `<head>`, чтобы не было вспышки. Системная тема слушает `matchMedia('(prefers-color-scheme: dark)')`.

Элемент управления — `<details class="settings">` в шапке: три группы radio. На мобильном панель раскрывается вниз и не перекрывает контент.

## Страницы

### `clubs.html`

- Шапка: бренд «Клубная платформа», ссылки «Клубы», «Подключить клуб», настройки, вход/кабинет.
- Hero: крупный заголовок, короткое объяснение, две кнопки, фото справа/на фоне.
- Панель поиска и фильтров по тарифам в одной карточке.
- Сетка клубов: карточка с бейджем тарифа, названием, адресом, режимом, телефоном, 2–3 преимуществами и действиями.
- Порядок элементов карточки фиксирован: бейдж и название сверху, метаданные, преимущества, кнопки.
- Тарифы: три равные карточки, без «белой» economy на тёмном фоне; цвета тарифов только как тонкая метка.
- CTA «Подключить клуб» — спокойный блок с одним действием.

### `profile.html`

- Если нет сессии — редирект на `/login.html?next=/profile.html`.
- Шапка: имя пользователя, роль, кнопка «Выйти».
- Сводка: активные брони, заявки, клубы.
- «Мои брони»: клуб, места, дата, время, кнопка отмены с подтверждением.
- «Мои заявки»: название клуба, тариф, статус, дата.
- «Настройки вида»: те же три группы, что в шапке.
- Пустые состояния с понятным следующим шагом.

### `login.html` / `index.html`

- Двухколоночный макет на широком экране: форма + короткий блок преимуществ.
- Поля с видимыми подписями, ошибки под формой, кнопка на всю ширину.
- Ссылки на соглашение и политику остаются.

### `apply.html`

- Форма в спокойной карточке, поля с подписями, группировка по смыслу.
- Пояснение этапов проверки, без обещаний сроков.

### `terms.html` / `privacy.html`

- Привести к общей палитре и типографике.
- Сохранить предупреждение о демо-шаблоне и места для реквизитов.

## Личный кабинет и API

Добавить `GET /api/me/bookings` (requireAuth):
- возвращает все активные будущие брони пользователя по всем клубам;
- поля: `id`, `start`, `end`, `club: { name, slug }`, `seats[].seat { name, zone }`;
- сортировка по `start`.

Существующий `DELETE /bookings/:id` уже проверяет владельца и не зависит от выбранного клуба.

## Админка (следующий этап)

- Сгруппировать вкладки: «Клуб», «Брони», «Контент», «Заявки», «Тариф».
- На мобильном — карточки вместо горизонтальной ленты.
- Не менять API админки на этом этапе.

## Файлы

- `public/theme.css` — токены, темы, акценты, общие компоненты.
- `public/theme.js` — применение и сохранение настроек, системная тема.
- `public/clubs.html`, `public/clubs.js` — новая витрина клубов.
- `public/profile.html`, `public/profile.js` — личный кабинет.
- `public/login.html`, `public/index.html`, `public/apply.html`, `public/terms.html`, `public/privacy.html` — общая шапка/стили.
- `public/assets/club-bg.jpg` — фото.
- `app.js` — новый маршрут `/api/me/bookings`.

## Проверка

- `clubs.html`, `profile.html`, `login.html`, `terms.html` отдают 200.
- Playwright: 1440×900 и 390×844, светлая и тёмная тема, все три акцента, фото и без фото.
- Настройки сохраняются после перезагрузки; нет вспышки темы.
- Нет горизонтальной прокрутки на 360 px.
- `GET /api/me/bookings` без сессии — 401, с сессией — список.
- `DELETE /bookings/:id` отменяет только свою бронь.
- Консоль без ошибок; тексты не обрезаются.

## Риски

- `style.css` используется старыми страницами; новые стили не должны ломать `menu.html` и `club.html`.
- Фото может быть слишком ярким; спасают градиент и обесцвечивание.
- Тема в `localStorage` не синхронизируется между устройствами — это осознанно, без изменений БД.
- Юридические страницы остаются демо-шаблоном до получения реквизитов.
